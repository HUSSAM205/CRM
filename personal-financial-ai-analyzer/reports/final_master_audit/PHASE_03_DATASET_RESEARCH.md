# Phase 3: Supplementary Dataset Research

Status: **COMPLETE**.

**Search** (2026-11-27): Hugging Face, UCI, OpenML, IEEE DataPort, Kaggle (via web search). Candidates and the reasons for each decision are in `docs/DATASET_REGISTRY.md` § Rejected or unused candidates.

**Selected:** PersonaLedger (Capital One Research), as Dataset B.
* **Licence:** **CC BY 4.0**, read from the dataset card (`license: cc-by-4.0`). It is not gated. Academic and commercial use are allowed with attribution; redistribution is allowed with attribution and an indication of changes.
* **Provenance:** synthetic transactions generated by persona-conditioned LLMs plus a rule-based accounting engine (dataset card). Revision `c90078ae4ac47e582c9263579466a905fa4adfab`.
* **Downloaded:** only the 2 files needed (275.6 MB), each with SHA-256 equal to the official LFS hash (`scripts/download_supplementary.py` re-verifies).
* **Storage:** `data/supplementary/`, git-ignored, with a regression test that it is never tracked.
* **Quality audit:** `reports/experiments/dataset_b/quality.json`.
* **Isolation:** separate dataset ID, separate experiments (E2-B, E3-B), no merging with A, no currency mixing (the source states no currency; it is treated as one unstated unit).

**Dataset C:** a controlled synthetic generator with known ground truth (`scripts/research/controlled_synthetic.py`). It is never presented as real-world validation.

**Not done:** no real (non-synthetic) personal transaction dataset with an open licence was found. Real-world validity therefore remains **unverifiable** (a documented limitation).
